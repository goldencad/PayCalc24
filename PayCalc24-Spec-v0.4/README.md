# PayCalc24 Specification Pack v0.4

**Stack:** .NET 9 / ASP.NET Core 9 / MariaDB / Avalonia / Actipro  
**Architecture:** Modular Monolith / Dynamic Formula Repository / Localization-first / Ribbon desktop UX

v0.4 adds three UI-platform requirements before Codex continues beyond Task 01:

1. Multi-language UI (`vi-VN`, `en-US` initially).
2. Actipro Ribbon + Backstage desktop application shell.
3. System / Light / Dark theme modes integrated with the Media-owned semantic SVG icon system.
