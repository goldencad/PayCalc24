# PayCalc24 — Use Cases & Screen Flow Summary
Main monthly flow:
`Select Company → Open/Create Payroll Period → Load Subjects → Import Attendance → Load Inputs/KPI → Validate → Calculate → Explain/Review → Funding Review → Approve → Lock → Statutory/Net → Report/Export`.

Primary screens:
Dashboard, Payroll Period Workspace, Organization, Assignment, Attendance Import/Evaluation, Input Ledger, Performance, Validation, Payroll Results, Explain Payroll, Funds/Coverage, Funding Review, Simulation, Approval, Integration, Reports and Audit.
