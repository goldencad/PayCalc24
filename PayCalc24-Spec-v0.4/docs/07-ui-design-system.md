# PayCalc24 — UI Design System
Primary client: Avalonia + Actipro.

## Rules
- Desktop-first, cross-platform Windows/macOS/Linux.
- Feature-oriented UI modules.
- Shared `Pc*` components wrap Avalonia/Actipro controls.
- No payroll business logic in XAML/ViewModels.
- Dynamic Pay Components/KPI/Funds render from metadata.
- All icons use semantic `IconKey`.
- All user-facing strings use localization resources.
- Theme modes: System / Light / Dark.
- Centralized typography, spacing, radius, surface, border and semantic status tokens.
